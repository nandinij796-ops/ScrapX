# ScrapX

ScrapX is an automotive repair ecosystem that connects car owners, roadside mechanics, scrap dealers, and spare-parts suppliers to reduce vehicle downtime through fast and affordable repair solutions.

## Development

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

Run the production build and ESLint checks with:

```sh
npm run build
npm run lint
```

The frontend is built with React and Vite and uses Firebase for application services.
